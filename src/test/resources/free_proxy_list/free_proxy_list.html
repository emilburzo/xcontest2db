Free Proxy List FAQ

Free proxies, the IPs and ports above, and what each column means

What is a free proxy list?

A public table of IP:port pairs that anyone can copy without signing up. Each row is a third-party machine that answered at the last check. We do not run those servers, so a row can stop working at any time.

The list suits a few manual checks in a browser. Anything longer should expect retries, because the addresses are shared with everyone who reads this page.

How often is the list updated?

The list is updated every minute. The Last Checked value shows how fresh each row is, and addresses that stop answering are dropped once a later check fails. The timestamp above the table is the moment the page itself was rebuilt.

How do I use a proxy from the list?

Pick a row, copy the IP and port from the first column, and paste them into the proxy settings of your browser, system or script. Choose HTTP as the proxy type unless your tool asks for something else; the port number is the same either way. Test it on a page that shows your IP before you put it in a long job.

How do I copy the whole list at once?

Use the Copy button above the table. It opens the raw list as text, which you can select and paste into a file. The table holds the newest rows, so the raw list is the better source when you need the full set.

What do the Protocol, Anonymity and Https columns mean?

Protocol is the kind of proxy the address speaks: HTTP, SOCKS4 or SOCKS5. Anonymity has three levels: elite proxies do not pass your IP in headers, anonymous proxies hide it, and transparent proxies pass it through. Https shows whether the proxy accepted an HTTPS tunnel at the last check, which an HTTP proxy does with the CONNECT method.

Are free proxies safe?

No. These are public machines run by strangers. HTTPS stops the proxy from reading page content, but it still sees which sites you connect to, and it can log, block or change unencrypted traffic. Do not sign in to accounts or send payment details through a free proxy, and do not route work traffic through one.

Where do these proxies come from?

Open proxy sources publish new addresses all day, and we add each one to the pool only after it answers a test. Anyone can run one of those servers, which is why we can tell you whether an address works and nothing more about who runs it.

How long does a free proxy last?

Anywhere from a few minutes to a few days. A machine drops out when its owner shuts it down, changes the port or puts it behind a firewall, and a busy address is blocked by the sites it hits. The Last Checked column is the only reliable clue you have.

Can I scrape websites with these proxies?

For small jobs, yes: use one address per request and wait between requests. Big sites block public proxy ranges, so a request through a free address usually returns a CAPTCHA or an error. Our rotating proxy is the option for larger crawls.

Do these proxies hide my IP?

The site you visit sees the proxy's IP, not yours. Whether it also sees your real IP depends on the anonymity level: transparent proxies pass it in headers, anonymous and elite proxies do not. Your ISP can still see that you are connecting to a proxy.

Can I pick a proxy from a specific country?

Yes. Use the Code or Country column to find one, or filter the raw list by country code after you copy it. The pool covers 131 countries today, though some countries only have a handful of addresses. Our datacenter proxies cover more countries per plan.

Why are some proxies slow or dead?

They are public machines collected from the internet, often on home connections or overloaded servers. Anyone can use them, so bandwidth disappears without notice. A row that passed the last check can still be dead by the time you connect to it.

  What is a subnet?

The IPs in A.B.C.0 ~ A.B.C.255 (ex. 11.22.33.0 ~ 11.22.33.255) are in the same subnet.

It's easy for websites to trace or block IPs from the same subnet.

Other vendors usually sell 10K proxies in 50 subnets. Our subnets are much more.
